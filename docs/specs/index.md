# Technical Specifications & PRDs

This directory archives historical Product Requirement Documents (PRDs) and technical specifications that define feature releases and architectural deepenings in PerGo.

---

## Specifications Directory

1. **[Product Requirements Document (PRD)](prd.md)**: Original enterprise requirements document defining throughput, latency, and self-hosted CPaaS architecture.
2. **[Architecture Deepening](architecture-deepening.md)**: Refactoring and deepening of Worker, Inbound, Types, and Credential ports.
3. **[Headless CPaaS Specification](headless-cpaas.md)**: Programmatic REST APIs for workspace provisioning, device pairing, and SSO hand-off.
4. **[Broadcaster Engine & Campaign Gateway (v1.8)](v1.8-broadcaster-gateway.md)**: Mass messaging campaigns, contact tagging, rate limiting, and HMAC webhook security.
5. **[WhatsApp Interactive & Flows Engine (v1.9)](v1.9-whatsapp-interactive-flows.md)**: WhatsApp Interactive messages (buttons, list pickers) and native Meta Flow data exchange encryption.
