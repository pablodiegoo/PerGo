### Task 3: Implement In-Memory Cache in WABATemplateRepository
<type>feature</type>
<files>
  - internal/repository/waba_template.go
</files>
<read_first>
  - internal/repository/waba_template.go
</read_first>
<action>
Add a `sync.RWMutex` and `cache map[uuid.UUID]map[string]*WABATemplate` to `WABATemplateRepository`. The cache keys should be `ConnectionID` mapping to an inner map with key `fmt.Sprintf("%s_%s", tpl.Name, tpl.Language)`. Add a `LoadCache(ctx context.Context)` method that performs a `SELECT * FROM waba_templates` and populates the map. Update read methods (`GetByNameAndLanguage`, etc.) to read from the cache first. Update write methods (`Create`, `Upsert`, `UpdateStatus`, `Delete`) to mutate the cache synchronously after successful DB execution.
</action>
<acceptance_criteria>
  - `WABATemplateRepository` struct contains `cache` and `mu`
  - `LoadCache` method exists and populates the cache
  - `GetByNameAndLanguage` returns from cache without executing SQL
</acceptance_criteria>
