  - internal/client/waba_meta.go
</files>
<read_first>

<action>
Implement an in-memory 15-minute rate limit per WABA ID within `WABAMetaClient` (using `sync.Mutex` and a map of `wabaID` to `time.Time`). If `SyncTemplates` is called before the 15-minute window expires for a given `wabaID`, return a clear rate-limit error (e.g., `ErrSyncRateLimited`) to prevent hitting Meta API limits.
</action>

  - After 15 minutes, `SyncTemplates` proceeds to make the HTTP request
</acceptance_criteria>
