### Task 1: Create Admin UI Route Handlers
<type>feature</type>

  - internal/api/handler/admin/waba_template.go
  - internal/api/router/admin_router.go
</files>
<read_first>
  - internal/api/handler/admin/waba_template.go
</read_first>
<action>
Create `internal/api/handler/admin/waba_template.go`. Implement handlers for `GET /connections/:slug/templates` (List), `GET /connections/:slug/templates/new` (Form), and `POST /connections/:slug/templates/sync` (Trigger Sync). Also add a POST handler to process form submissions which delegates to `WABAMetaClient` and `WABATemplateRepository`. Register these in `admin_router.go`.
</action>
<acceptance_criteria>
  - Handlers for rendering template list, form, and triggering manual sync are implemented
  - Routes are registered under `/connections/:slug/templates`
  - POST `/connections/:slug/templates/sync` triggers `WABAMetaClient.SyncTemplates`
</acceptance_criteria>

### Task 2: Build Template List View
<type>feature</type>
<files>
  - ui/views/waba_template/list.templ
</files>
<read_first>
  - ui/views/waba_template/list.templ
</read_first>
<action>
Create `ui/views/waba_template/list.templ`. Render a table listing templates with columns for Name, Language, Category, and Status. Status should use DaisyUI colored badges: green (APPROVED), yellow (PENDING), red (REJECTED), gray (PAUSED/DISABLED). Include an expandable row or prominent inline text for `RejectionReason` if the status is REJECTED. Render a prominent "Sync Templates" button at the top of the view that triggers `hx-post="/connections/:slug/templates/sync"` with rate-limit status feedback (per D-08, TMPL-03).
</action>
<acceptance_criteria>
  - Table renders with correctly mapped status badge colors
  - Rejection reason is visible for REJECTED templates
  - "Sync Templates" button triggers manual sync via HTMX post and displays rate limit messages if triggered within 15 minutes
</acceptance_criteria>
