<objective>
Render formatted visual order summary bubbles and catalog product cards in the admin Inbox Chat UI for inbound WhatsApp orders and outbound product dispatches using Templ and Tailwind CSS.
</objective>

<tasks>

<task id="T1" title="Implement Inbound Order Summary & Outbound Product Card Templ Bubbles">
<read_first>
- templates/components/message_bubble.templ
- internal/domain/message.go
</read_first>
<action>
Modify `templates/components/message_bubble.templ`:
1. Add helper function `parseOrderMetadata(metadata map[string]string)` (or parse raw message metadata/body) to extract order details (`catalog_id`, `items`, `total_price`, `currency`, `customer_note`).
2. Update `MessageBubble(m repository.ThreadMessage)`:
   - **Inbound Order Summary Bubble**: If `m.Direction == "inbound"` and metadata contains `type == "order"` or body starts with order indicators:
     - Render white container with rounded corners and border.
     - Display top badge: 🛒 **Pedido do Catálogo** `<catalog_id>`.
     - Display items table with headers: Item / Qtd / Preço.
     - Display subtotal and currency badge (e.g. `Total: R$ 149.90 BRL`).
     - Display customer note callout if present.
   - **Outbound Product Card**: If `m.Direction == "outbound"` and metadata/type indicates `product` or `product_list`:
     - Render blue/zinc catalog product card container.
     - Display catalog ID badge and product section header.
     - Display section title and list of product SKUs.
</action>
<acceptance_criteria>
- Inbound order messages render as styled summary cards with item list, total price, and customer notes.
- Outbound product messages render as formatted catalog cards.
</acceptance_criteria>
<verify>
go test ./templates/components/... -run TestMessageBubble_OrderAndProduct
</verify>
</task>
