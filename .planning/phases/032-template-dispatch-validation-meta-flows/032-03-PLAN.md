<objective>
Support `type: "flow"` Meta interactive messages in the WABA dispatch pipeline and auto-generate secure HMAC `flow_token`s.
</objective>

<tasks>

<task id="T1" title="Extend Interactive Domain for Flows">
<read_first>
- internal/domain/message.go
</read_first>
<action>
Update the `domain.Interactive` struct to support Flow-specific properties:
Add fields `FlowToken` (string), `FlowID` (string), `FlowCTA` (string), `FlowAction` (string), and `FlowActionPayload` (map[string]interface{}).
</action>
<acceptance_criteria>
- Domain structs can fully represent a Meta Flow payload.
</acceptance_criteria>
<verify>
go test ./internal/domain/...
</verify>
</task>

<task id="T2" title="Map Flow struct in WABA Dispatch">
<read_first>
- internal/channel/whatsapp/waba.go
</read_first>
<action>
Modify `WABAAdapter.Dispatch()`:
1. When mapping `m.Interactive`, if `Type == "flow"`, map the domain properties into the equivalent `wabaInteractiveAction` Meta API struct.
2. Set `action.name` to `"flow"`.
3. Set `action.parameters` with `flow_message_version: "3"`, `flow_id`, `flow_cta`, etc.
</action>
<acceptance_criteria>
- The outbound JSON to Meta Graph API strictly conforms to the Meta Flows API schema.
</acceptance_criteria>
<verify>
go test ./internal/channel/whatsapp/... -run TestWABAAdapter_DispatchFlow
</verify>
</task>

<task id="T3" title="Generate HMAC-SHA256 flow_token">
<read_first>
- internal/channel/whatsapp/waba.go
</read_first>
<action>
In `WABAAdapter.Dispatch()`, right before mapping the flow:
If `m.Interactive.FlowToken` is empty, generate an HMAC-SHA256 signed token.
Use the workspace ID or a connection secret as the key.
Encode a JSON payload containing: `workspace_id`, `recipient_phone`, `flow_id`, `timestamp` (current), and a random `nonce`. Base64 encode the final signed payload and assign it to `flow_token`.
</action>
<acceptance_criteria>
- Sent Flow messages always include a valid `flow_token`, either provided by the API consumer or safely auto-generated.
</acceptance_criteria>
<verify>
go test ./internal/channel/whatsapp/... -run TestWABAAdapter_FlowTokenGeneration
</verify>
</task>

</tasks>

<must_haves>
<truths>
- Meta Flows can be dispatched via `POST /messages` identically to standard interactive messages.
- Generated `flow_token`s prevent replay attacks via embedded timestamps and nonces.
</truths>
</must_haves>
