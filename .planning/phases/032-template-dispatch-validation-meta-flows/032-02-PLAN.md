<objective>
Implement smart fallback to upgrade freeform messages to a default template when the 24h session window is closed.
</objective>

<tasks>

<task id="T1" title="Implement Smart Session Window Fallback">
<read_first>
- internal/outbound/processor.go
- internal/session/window.go
</read_first>
<action>
In `Processor.Ingest()`, at the session window check (step 4.5):
1. If `req.Type` is not template and `IsWindowOpenBool()` is `false`, check if the connection has a `DefaultTemplateName` configured.
2. If `DefaultTemplateName` is missing, return HTTP 422 `session_window_expired` (existing behavior).
3. If `DefaultTemplateName` is present, mutate the request:
   - Change `req.TemplateName` to the connection's `DefaultTemplateName`.
   - Clear `req.Body` and populate `req.Components` with a single body component where `text` is the original freeform `req.Body` mapped to parameter `{{1}}`.
   - Set `req.Language` to the connection's default language fallback.
4. Pass the mutated request through the template validation logic from Plan 01.
</action>
<acceptance_criteria>
- Freeform messages sent to expired sessions automatically transform into template messages if a default template is configured.
- The freeform text correctly binds to the first parameter of the template body.
</acceptance_criteria>

</verify>
</task>
