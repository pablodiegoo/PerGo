<objective>
Implement a background ticker to detect sessions nearing expiration (at the 23h or 71h mark) and emit `session.expiring_soon` webhook events.
</objective>

<tasks>

### Task 1: Implement SessionTicker
<read_first>
- internal/repository/recipient_session.go
</read_first>
<action>
Create a new file `internal/session/expiring_ticker.go`. Define a `SessionTicker` struct holding a `RecipientSessionRepository` and a `Publisher` (for NATS). Implement a `Run(ctx context.Context)` loop with a `time.NewTicker(5 * time.Minute)`. On each tick, call `repo.GetExpiringSessions(ctx, start, end)` where `start` and `end` window targets sessions exactly 23 hours (for standard) or 71 hours (for ctwa) old. For each found session, emit a `session.expiring_soon` event to the `"webhooks.events"` NATS subject, and immediately call `repo.MarkNotifiedExpiring(ctx, ...)` to prevent duplicate events.
</action>
<acceptance_criteria>
- `SessionTicker` struct and `Run` method are implemented.
- Ticker uses a 5-minute interval.
- Fetches sessions nearing expiration and emits `session.expiring_soon`.
- Marks sessions as notified immediately after emission.
</acceptance_criteria>
