</objective>

### Task 2: Extend IsWindowOpen signature and logic
<read_first>
- internal/session/window.go
</read_first>
<action>
Modify `IsWindowOpen` in `internal/session/window.go` to have the signature: `IsWindowOpen(ctx context.Context, workspaceID uuid.UUID, recipientPhone string, channel string, recipientIdentity string, safetyBuffer time.Duration) (*WindowStatus, error)`. Retrieve the session; if not found, it's not open. Read `entry_point_type` from the session. If `entry_point_type == "ctwa"`, use `WindowDuration = 72 * time.Hour`, otherwise `24 * time.Hour`. Calculate `ExpiresAt = lastInboundAt.Add(WindowDuration)`. Calculate `cutoff = ExpiresAt.Add(-safetyBuffer)`. Set `Open = time.Now().UTC().Before(cutoff)`. Return the populated `*WindowStatus`.
</action>
<acceptance_criteria>
- `IsWindowOpen` signature accepts `safetyBuffer time.Duration` and returns `*WindowStatus, error`.
- Logic uses 72h window if `entry_point_type` is `"ctwa"`, else 24h.
- Open state is evaluated using `cutoff` which accounts for `safetyBuffer`.
</acceptance_criteria>
<verify>
grep -A 2 "func (c \*WindowChecker) IsWindowOpen" internal/session/window.go
</verify>
