<objective>
Update the `ConnectionRepository` to support the new `slug` column in all SQL queries, add `Slug` to the `Connection` struct, and implement an in-memory cache to support fast route resolution (D-08).
</objective>

<task id="02.1">
<title>Update Connection Struct and Queries</title>
<type>code</type>
<read_first>
- internal/repository/connection.go
</read_first>
<action>
Modify `internal/repository/connection.go`.
1. Add `Slug string json:"slug"` to the `Connection` struct.
2. Update the `INSERT` query in `Create` to include `slug`.
3. Update `scanAndDecrypt` and `scanRowAndDecrypt` to scan the `slug` column.
4. Update all `SELECT` queries (`GetByID`, `GetBySenderIdentity`, `GetByJID`, `GetDefaultChannelConnection`, `ListByWorkspace`, `ListAll`) to fetch the `slug` column.
</action>
<acceptance_criteria>
- `Connection` struct contains `Slug string`
- `Create` method explicitly inserts the `slug` column
- All `SELECT` queries in the repository list `slug` in the projection
</acceptance_criteria>
</task>

<task id="02.2">
<title>Implement Connection Cache</title>
<type>code</type>
<read_first>
- internal/repository/connection.go
</read_first>
<action>
1. Add `slugCache map[string]*Connection` and `mu sync.RWMutex` to the `ConnectionRepository` struct.
2. Update `NewConnectionRepository` to initialize the `slugCache`.
3. Implement `GetBySlug(ctx context.Context, workspaceID uuid.UUID, slug string) (*Connection, error)`.
   - The method should check the cache using `workspaceID.String() + ":" + slug`.
   - On cache miss, query the database, populate the cache, and return.
4. Invalidate/update the cache in `Create`, `UpdateStatus`, `Delete`, and `SaveCredentials`. When a connection is modified or deleted, remove or update its entry in `slugCache`.
</action>
<acceptance_criteria>
- `ConnectionRepository` contains `slugCache map[string]*Connection` and `mu sync.RWMutex`
- `GetBySlug` method exists with signature `func (r *ConnectionRepository) GetBySlug(ctx context.Context, workspaceID uuid.UUID, slug string) (*Connection, error)`
- Cache is correctly invalidated on `Delete` and `UpdateStatus`
</acceptance_criteria>
</task>

<verify>
Run `go test ./internal/repository/... -run TestConnection` to ensure no SQL syntax errors were introduced and that caching correctly falls back to the database.
</verify>

<must_haves>
<truths>

</must_haves>
