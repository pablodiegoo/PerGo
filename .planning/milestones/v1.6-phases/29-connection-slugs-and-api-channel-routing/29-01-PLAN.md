<type>code</type>

<action>
Create `internal/pkg/slug/slug.go` and `internal/pkg/slug/slug_test.go`.
Implement a `Generate(name string) string` function that:
1. Converts the string to lowercase.
2. Replaces spaces and underscores with hyphens (`-`).
3. Removes all non-alphanumeric characters (except hyphens).
4. Strips leading/trailing hyphens and deduplicates consecutive hyphens.
This ensures the output matches the `^[a-z0-9-]+$` regex requirement.
</action>
<acceptance_criteria>
- `slug.Generate("Vendas SP")` returns `"vendas-sp"`
- `slug.Generate("Suporte_Técnico!!")` returns `"suporte-tcnico"`
- Function `Generate` exists with signature `func Generate(name string) string`
</acceptance_criteria>
</task>

<task id="01.2">
<title>Create DB Migration for Slugs</title>
<type>code</type>
<read_first>
- .planning/phases/29-connection-slugs-and-api-channel-routing/29-CONTEXT.md
- internal/platform/postgres/migrations/001_create_schema.sql

<action>
Create `internal/platform/postgres/migrations/030_connection_slugs.sql`.
1. `ADD COLUMN slug VARCHAR(255);`
2. Backfill slugs using `LOWER(REGEXP_REPLACE(name, '[^a-zA-Z0-9]', '-', 'g'))` or a combination of `name` and `channel`. To handle duplicates, use a CTE with `ROW_NUMBER() OVER (PARTITION BY workspace_id, slug)` to append suffixes like `-1`, `-2`.
3. `ALTER COLUMN slug SET NOT NULL;`
4. `CREATE UNIQUE INDEX idx_connections_workspace_slug ON connections(workspace_id, slug);`
</action>
<acceptance_criteria>
- The migration file `030_connection_slugs.sql` exists.
- The migration contains `CREATE UNIQUE INDEX idx_connections_workspace_slug ON connections(workspace_id, slug)`.
- The migration successfully runs on a database with existing connections without violating `NOT NULL` or `UNIQUE`.
</acceptance_criteria>
</task>
