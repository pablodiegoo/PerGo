<objective>
Parse inbound Meta WhatsApp order webhooks (`messages[].type == "order"`), perform idempotent `wamid` deduplication, and emit normalized `order.created` events to workspace webhooks and JetStream topics.
</objective>

<tasks>

<task id="T1" title="Inbound Order Webhook Parsing in WABAInboundAdapter">
<read_first>
- internal/channel/whatsapp/waba_inbound.go
- internal/domain/event.go
</read_first>
<action>
Modify `WABAInboundAdapter.Parse` in `internal/channel/whatsapp/waba_inbound.go`:
1. Extend `Messages` struct in `ValueData` to include Meta order payload fields:
   ```go
   Order *struct {
       CatalogID    string `json:"catalog_id"`
       Text         string `json:"text,omitempty"`
       ProductItems []struct {
           ProductRetailerID string  `json:"product_retailer_id"`
           Quantity          string  `json:"quantity"`
           ItemPrice         string  `json:"item_price"`
           Currency          string  `json:"currency"`
       } `json:"product_items"`
   } `json:"order,omitempty"`
   ```
2. When `msg.Type == "order"` and `msg.Order != nil`:
   - Parse items, convert quantity and item_price defensively to `int` and `float64`.
   - Calculate order total price $\sum (\text{quantity} \times \text{item\_price})$.
   - Construct human-readable summary for `InboundEvent.Body` (e.g., `"🛒 Order Received (Catalog: <cat_id>)\nItems: ..."`).
   - Attach raw order JSON details inside `InboundEvent.Metadata["order_json"]` and `Metadata["type"] = "order"`.
</action>
<acceptance_criteria>
- Inbound `type == "order"` webhooks are parsed into `InboundEvent` with structured metadata and formatted summary body.
- Quantity and item prices are parsed accurately without panic.
</acceptance_criteria>
<verify>
go test ./internal/channel/whatsapp/... -run TestWABAInboundAdapter_OrderParsing
</verify>
</task>

<task id="T2" title="Publish Order Created Events & Idempotent Wamid Deduplication">
<read_first>
- internal/inbound/processor.go
- internal/api/handler/waba_webhook.go
</read_first>
<action>
1. In `internal/inbound/processor.go`, add `PublishOrderCreated` method:
   ```go
   func (p *InboundProcessor) PublishOrderCreated(ctx context.Context, workspaceID uuid.UUID, ev *domain.OrderCreatedEvent) error
   ```
   Publishes serialized `OrderCreatedEvent` payload with `event: "order.created"` to NATS subject `inbound.events.<workspace_id>`.
2. In `internal/api/handler/waba_webhook.go`:
   - Detect inbound events with `event.Metadata["type"] == "order"`.
   - Perform `wamid` deduplication via `dedupRepo.InsertAndCheck(ctx, workspaceID, "whatsapp_cloud", event.MessageID)`.
   - If unique, construct `domain.OrderCreatedEvent` from `event.Metadata["order_json"]` and call `h.inboundProcessor.PublishOrderCreated(ctx, workspaceID, orderEv)`.
   - If duplicate, log and suppress duplicate `order.created` event emission.
</action>
<acceptance_criteria>
- `PublishOrderCreated` successfully emits `order.created` event payload to NATS.
- `wamid` deduplication prevents duplicate event emissions when Meta retries webhook calls.
</acceptance_criteria>
<verify>
go test ./internal/api/handler/... -run TestWABAWebhook_OrderDeduplication
</verify>
</task>
